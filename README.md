      <h3>When the network disappears.</h3>
      <p><strong>UPI Offline Mesh Payment System</strong></p>
      <p>A Spring Boot backend that routes payment packets through nearby peers when the originating device is offline.</p>
      <ul>
        <li><strong>RSA + AES-GCM</strong> keeps relays from reading or tampering with transactions.</li>
